# Fullscreen Image Gallery (Auto-Detect GitHub Folder)

## Struktur Folder
```
├── index.html
└── img/
    └── (masukkan semua file gambar Anda di sini, nama file bebas)
```

## Cara Pakai di GitHub Pages (100% Otomatis)
1. Ekstrak file ZIP ini.
2. Masukkan semua file gambar Anda (`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`, `.svg`) ke dalam folder `img/` — **tidak perlu mengganti nama file**.
3. Upload file `index.html` beserta folder `img/` ke repositori GitHub Anda (pastikan visibilitas repositori adalah **Public**).
4. Buka tab **Settings > Pages** di repositori GitHub Anda, pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Buka link GitHub Pages Anda (`https://username.github.io/nama-repo/`). Skrip akan otomatis mendeteksi username, nama repositori, dan seluruh isi gambar di dalam folder `img/`.
